① Monte Carlo 多路径前向模拟

基于多元正态假设 forward 投 3000 条净值路径，输出终值分布（与传统回测的历史复盘相对，看的是"未来可能性"）

# sandbox/backtest_engine.py def monte_carlo_paths(expected_returns, cov_matrix, weights, horizon_days=252, n_paths=10_000, seed=42): mu = np.asarray(expected_returns) sigma = np.asarray(cov_matrix) w = _normalize_weights(weights) daily_mu = mu / TRADING_DAYS daily_cov = sigma / TRADING_DAYS # 多元正态抽样：n_paths × horizon × n_assets samples = rng.multivariate_normal(daily_mu, daily_cov, size=(n_paths, horizon_days)) port_daily = samples @ w # 组合每日收益 cum_log_ret = np.sum(np.log1p(port_daily), axis=1) # 累计对数收益 terminal_returns = np.expm1(cum_log_ret) # 终值收益率 return { "terminal_values": initial_capital * (1.0 + terminal_returns), "terminal_returns": terminal_returns, "summary": {"p5": ..., "p50": ..., "p95": ..., "prob_loss": (terminal_returns < 0).mean()}, }

② VaR / CVaR：把 MC 分布转成可解释的损失数字

95% VaR = 最差 5% 路径的分位点；CVaR = 那 5% 路径的平均损失（更严格的尾部风险测度）

def value_at_risk(returns, confidence=0.95, initial_capital=1_000_000): alpha = 1 - confidence var_threshold = np.percentile(returns, alpha * 100) var_loss = -var_threshold # 损失为正 tail = returns[returns <= var_threshold] cvar_loss = -tail.mean() if tail.size > 0 else var_loss return {"confidence": confidence, "var_return": var_loss, "var_amount": var_loss * initial_capital, "cvar_return": cvar_loss, "cvar_amount": cvar_loss * initial_capital}

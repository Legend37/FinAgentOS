② 系统架构（控制与计算分离）

Layer 1 · Control

编排与控制

  • LangGraph 状态机
  • CoreRouter 意图路由
  • 5 个 Agent 节点（已解耦）
  • DeepSeek LLM 双调用接口（JSON / 文本）

Layer 2 · Computation

确定性沙箱

  • MVO 二次规划求解器（SLSQP）
  • 历史回测引擎（夏普 / 回撤）
  • Matplotlib 离线可视化

Layer 3 · Data & Memory

数据与持久层

  • DataOps：AkShare + yfinance + 缓存
  • RAG：TF-IDF + 父子块
  • SQLAlchemy + SQLite 持久层
  • 多轮会话切片管理

③ LangGraph 三分支流程

A ASSET_ALLOCATION · 全量管线（并行）
START →
Profile_P_t Screening_S_t
⤳ 并行汇合 ⤳ Sandbox_A_t (MVO) → Timing_T_t (LLM) → Risk_R_t (硬门禁+LLM) → END
B PORTFOLIO_REVIEW · 持仓审查（跳过 S_t / A_t）
START → Profile_P_t → Review → Timing_T_t → Risk_R_t → END
C CHIT_CHAT / QA_RAG · LLM 对话兜底
START → GeneralResponse (LLM 文本) → END

⑥ API 入口

POST /api/allocate

输入 JSON：

{
  "api_key": "sk-...",            // DeepSeek API Key（必填）
  "query": "我有 50 万想稳健配置",   // 自然语言诉求 → 触发意图路由
  "name": "张三",                  // 新增
  "age": 32,
  "occupation": "工程师",          // 新增
  "total_wealth": 500000,
  "risk_tolerance_level": "平衡型",
  "investment_horizon": "中长期",
  "financial_goals": "教育金储备",
  "custom_tickers": ["AAPL", "600519.SS"]  // 新增（可选，覆盖预设池）
}

输出 JSON：

{
  "intent": "ASSET_ALLOCATION",
  "assets": ["贵州茅台 (酒类消费)", "工商银行 (大型金融)", "比亚迪 (新能源车)"],
  "base_weights":  [0.42, 0.35, 0.23],   // MVO 沙箱基准
  "final_weights": [0.45, 0.30, 0.25],   // LLM 微调 + 风控放行
  "risk_status": "PASS",                  // PASS / FAILED / CHAT
  "timing_reason": "...",                 // 配置经理调整理由
  "risk_report":   "...",                 // 风控审计意见书
  "user_profile":  { ... },
  "asset_snapshot":{ ... }
}

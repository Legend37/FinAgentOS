BUGFIX 1

持仓体检：协方差矩阵 (0,) 与资产数 0 不一致

触发路径为 PORTFOLIO_REVIEW。当持仓是 Cash_Equivalents / Fixed_Income / Equities / Alternative_Assets 这类类别名而非真实 ticker 时，reviewer.py 拉不到行情，给出空 cov_matrix / expected_returns，却仍返回 4 个资产名与权重。RiskSim 节点已正确跳过，但 Critic._rerun_sandbox 缺同款守卫，只要 adjusted_weights 非空就硬跑沙箱，空协方差 (0,) 撞上 backtest_engine 的 shape 断言，并连刷 3 次 REVISE 才被安全阀放行。

# 日志现场 [Review] 已有持仓审查: ['Cash_Equivalents', 'Fixed_Income', 'Equities', 'Alternative_Assets'] (跳过 S_t/A_t) [RiskSim] 缺少基础权重/行情，跳过 [C_t] 沙箱重算失败: 协方差矩阵 (0,) 与资产数 0 不一致 # ← 报错 [C_t] Critic: REVISE (score=55) -> REVISE (score=45) -> APPROVE (retry=2) # ← 空转 3 次
修复前

_rerun_sandbox 无条件调用 comprehensive_risk_report；空协方差进维度校验抛错， Critic 拿不到量化对比 → 反复 REVISE 直到 retry≥2 强制放行（浪费 3 次 LLM 调用）。

修复后

_rerun_sandbox 先判 expected_returns / cov_matrix / available_assets 是否为空， 空则静默跳过（不报错）。Critic 检测到无量化基础时首轮即放行，不再空转。

文件改动
core_brain/agents/critic.py_rerun_sandbox 加空数据守卫；critic_node 在 has_quant=False 时与 retry 上限同等对待，首轮强制 APPROVE。
BUGFIX 2

风控节点：'list' object has no attribute 'get'

risk_officer.py 假设 LLM 返回 JSON 对象，直接 res.get("risk_status")。当模型返回 JSON 数组时崩溃，被 except 兜成假的“检查通过”——等于风控没真正执行。诱因之一是该节点 prompt 缺了外层 {}，弱模型（换接口/换模型后更易出现）容易返回成数组。修复采用两层防御： call_deepseek 统一对数组返回做解包容错（惠及全部 JSON 调用点），并补全 prompt 的对象格式约束。

call_deepseek 容错解包
data = json.loads(content) # 个别供应商不遵守 json_object， # 把对象包成数组返回 if isinstance(data, list): data = next( (x for x in data if isinstance(x, dict)), {}) return data
risk_officer prompt 补 {}
请严格输出 JSON 对象 （必须以 { 开头、} 结尾，不要返回数组）： { "risk_status": "PASS" 或 "FAILED", "risk_report": "..." }
文件改动
core_brain/agents/llm_client.pycall_deepseek 对 list 返回解包出首个 dict。
core_brain/agents/risk_officer.py审查 prompt 补全外层 {} 与“不要返回数组”约束。

已知约束

Token 计费表只认两个模型名

config.py 的 pricing 仅含 deepseek-chat / deepseek-reasoner。 换成其它模型 ID 时，estimate_cost() 回退按 deepseek-chat 价估算，费用数字会偏差 （不影响功能）。如需精确计费，可把定价表也做成可配置。

行情通道：东财→新浪双源 + 回测可降级模拟

回测/归因/选品的国内行情统一走系统代理（Clash），东财(em) 失败自动转新浪(sina)。 实测本机网络下 eastmoney 经 Clash 间歇性被掐（CONNECT 被 RemoteDisconnected），而新浪源稳定可达 （510300/518880/600519 实拉 18 行真实数据 ✅）。海外 yfinance 经代理已能拉真实数据。 运行前提：Clash 开 + 前端代理开关打开（TUN 模式更稳）。两源都拉不到时：归因显示 pending/unavailable（不造假）； 净值回测降级为 simulated=true 离线模拟，前端标「无参考意义」。

回测「模拟年化」为线性外推

短窗口（如近 30 天≈22 个交易日）的区间收益按 252/n 放大到一年，数字波动极大、 不代表未来表现，仅作直觉参考；卡片已显式标注。需稳健评估请拉长窗口或看区间收益本身。

json_object 兼容性

自定义 base_url 指向的第三方接口若不支持 response_format=json_object， 结构化调用可能返回非标准结果；已加数组解包容错，但仍建议优先选支持 JSON 模式的兼容服务。
